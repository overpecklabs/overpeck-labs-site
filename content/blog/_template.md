This is the template for new posts. Copy it to a new file in content/blog/ (for example
`content/blog/why-missed-calls-cost-jobs.md`), fill in the frontmatter above and set `published: true`
when it's ready. A published post appears on its date (America/New_York), so you can add posts ahead of time.
Files whose name starts with "_", like this one, never render.

Set `youtubeId` to a YouTube video ID (the part after `watch?v=`) to show a click-to-play video at the top of
the post. Leave it empty for no video. HTML comments like <!-- this --> are notes and don't render.

## A section heading

Write in plain Markdown: **bold**, *italics*, [links](/free-mockup), lists and quotes all work.

- A point
- Another point

Every post automatically ends with the "Test it out for yourself" call line and the free mockup link,
so there's no need to add them here.
